# Motion Vibe Playground

- The whole tool is `index.html`: vanilla HTML, CSS and JavaScript using the Web Animations API. Don't add libraries or a build step.
- To load a Figma frame into the playground, follow `.claude/skills/motion-figma/SKILL.md`.
- To add or scout animations, follow `.claude/skills/motion-scout/SKILL.md`.
- Motion rules and vibe values live in `.claude/skills/motion-vibes/SKILL.md`.
- The maintainer is a product designer, not a developer. Explain changes in plain language.
